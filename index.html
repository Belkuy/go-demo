go-demo

一个最小 Go 服务，演示从代码提交到镜像发布再到页面上线的完整 CI/CD 链路——全部免费，全部自动化。

📝 git push → 🤖 Actions 构建 → 📦 ghcr.io 镜像 → 🌐 Pages 上线
🤖

自动构建

push 到 main 即触发，Go 1.22 多阶段构建，产物镜像仅约 21MB，非 root 用户运行。

📦

镜像发布

镜像自动推送到 GitHub Container Registry：ghcr.io/belkuy/go-demo:latest，GITHUB_TOKEN 认证零配置。

🌐

页面托管

本页面由 actions/deploy-pages 自动发布，每次更新页面内容后自动重新上线。

⚡

API 演示

Go 服务监听 :8080，访问根路径返回版本号，版本在构建时通过 ldflags 注入。

本地拉取运行

# 拉取并运行（需包可见性为 public）
docker pull ghcr.io/belkuy/go-demo:latest
docker run --rm -p 8080:8080 ghcr.io/belkuy/go-demo:latest

# 验证
curl http://localhost:8080 # hello from go-demo, version: ...
